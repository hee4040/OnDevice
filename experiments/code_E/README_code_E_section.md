### 코드 실행 및 재현 안내

1. Colab GPU와 Google Drive를 연결하고 기존 ImageNet-1K validation 50,000장, ThinkingViT 공식 수정 `timm`, 체크포인트를 준비한다.
2. 노트북의 환경/평가 스크립트 생성 셀을 **위에서 아래로 실행**한다.
3. `RUN_E123_SMOKE`, `RUN_E123_FULL`, `RUN_E1_RATIO_DIAG`, `RUN_E3_ALPHA_DIAG`, `RUN_MISSING_E4_EVALUATIONS`, `RUN_E4_TRAIN_FROM_200`은 기본적으로 꺼져 있다. 기존 Drive 결과를 재사용한다.
4. 공동 평가 스크립트에 포함된 E2 코드는 E1/E3의 기존 평가 의존성을 위해 **보존**했으며, 이 브랜치 문서의 결과 보고 범위는 E1/E3/E4이다.
5. 코드의 정적 문법과 Notebook 형식은 검증했지만 Colab GPU 및 팀 체크포인트에서 재실행을 완료한 것은 아니다.

### 해석상 주의

- E1/E3는 **dense accuracy oracle**이다. 측정하지 않은 FLOPs 또는 Latency 감소를 주장하지 않는다.
- E4의 Drop 유지율 평가와 E1/E3의 동적 3H→6H 비교는 **서로 다른 평가 조건**이다.
- E4 200→500 step 정확도 하락의 인과 원인은 검증하지 않았다.
- 기존 팀 연구(`experiment/h1-attention-full-mlp-selective`, `experiment/drop-ft` 등)와 차별성을 먼저 확인해야 하며, 독립적 신규 아이디어로 단정하지 않는다.
